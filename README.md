meu trabalho de miniprojeto do curso de analise de dados da sctec

Este projeto foi feito para analisar uma base de dados de varejo usando Python e a biblioteca Pandas. A ideia principal foi pegar os dados de vendas e clientes, verificar se eles estavam organizados corretamente, encontrar possíveis problemas e depois fazer algumas análises para descobrir informações úteis, fazendo importação, limpeza, organização e análise dos dados. a principal biblioteca foi o Pandas, para que fosse possivel abrir o arquivo CSV, verificar as informações, limpar os dados e fazer os agrupamentos e cálculos necessários. Depois o Google Drive foi conectado ao Google Colab para acessar o arquivo varejo no drive, usando o "pd.read_csv()" para ler um arquivo CSV e transformar seus dados em uma tabela que o Pandas consegue trabalhar, o "sep=";"" foi utilizado porque os dados do arquivo são separados por ponto e vírgula e também foi removida uma possível coluna chamada Unnamed, evitando deixar no DataFrame uma coluna que não faz parte dos dados importantes da análise.

Depois da importação, foram verificadas as colunas "print(Varejo.columns)" Esse comando mostra os nomes das colunas existentes na tabela. Também foi utilizado os "print(Varejo.shape)" e "print(Varejo.dtypes)". O shape mostra a quantidade de linhas e colunas da tabela, já o dtypes mostra o tipo de dado de cada coluna, ajudando a identificar se alguma informação precisa ser convertida. depois, antes de analisar os dados, foi necessário procurar possíveis problemas. O código "Varejo.isnull().sum()" conta quantos valores vazios existem em cada coluna enquanto para verificar linhas repetidas, foi utilizado o "Varejo.duplicated().sum()" Isso mostra quantas linhas completamente duplicadas existem na tabela.

A base também possuía categorias representadas por #N/D, então verificamos "(Varejo == "#N/D").sum()" Depois, esses valores foram substituídos por uma informação mais clara "Varejo["PR_CAT"] = Varejo["PR_CAT"].replace("#N/D", "Sem Categoria")" Foi utilizado Sem Categoria porque o produto não possuía uma categoria informada. Assim, em vez de deixar #N/D, fica mais fácil entender o que aconteceu e o if foi utilizado para verificar se realmente existia algum #N/D antes de fazer a substituição. Depois da verificação, as linhas completamente duplicadas foram removidas e a coluna DATA também foi convertida para o formato de data "Varejo["DATA"] = pd.to_datetime( Varejo["DATA"], format="%d/%m/%Y" )" Isso é importante porque uma data não deve ser tratada apenas como um texto. Transformando para datetime, fica mais fácil fazer análises envolvendo datas. A coluna CL_FHL, que representa o número de filhos do cliente, foi transformada em número inteiro,Já CO_ID, CL_ID e PR_ID não foram convertidos para números porque são identificadores. Mesmo parecendo números, eles funcionam como códigos.

Logo após,para entender que cada linha representa um item de uma compra e não necessariamente uma compra inteira. (Por isso o CO_ID aparece várias vezes) Para verificar quantos itens estavam associados a cada compra, foi utilizado o "itens_por_compra = Varejo.groupby("CO_ID").size()". O "groupby()" agrupa os dados de acordo com uma determinada informação, nesse caso, os registros foram agrupados pelo CO_ID, permitindo ver quantos itens pertenciam a cada compra. Depois fazemos uma análise da coluna CL_FHL e fizemos os calculos da média, mediana, desvio padrão, moda, valor maximo e minimo, contagem e quartis e vamos para o agrupamento por genero. onde analisamos a quantidade com o "genero_do_cliente = Varejo.groupby("CL_GENERO").size()" depois calculamos a quantidade de compr de cada gênero com o "compras_por_genero = Varejo.groupby("CL_GENERO")["CO_ID"].nunique()". O "nunique()" serve para contar os CO_ID diferentes, e não simplesmente contar todas as linhas para evitar quantidade de cada item com quantidade de compras.

E, para concluir, a análise da coluna CL_FHL ajudou a entender melhor a quantidade de filhos dos clientes por meio de diferentes cálculos, o agrupamento por CL_GENERO permitiu observar diferenças na quantidade de itens registrados entre os gêneros e também foi possível analisar a quantidade de compras diferentes para cada gênero usando as colunas CL_GENERO e CO_ID, e durante a análise, foi importante perceber que o CO_ID pode aparecer várias vezes porque cada linha representa um item de uma compra. na limpeza dos dados, foram removidas linhas duplicadas e a coluna DATA foi transformada para o formato de data e os valores #N/D encontrados nas categorias foram substituídos por Sem Categoria, deixando os dados mais fáceis de entender.
